# Voxel North Eastern & Twelve Lab Hackathon

This repository (fork) includes materials for the Voxel North Eastern and Twelve Lab Hackathon.

## Overview
- Purpose: Share the project and instructions so anyone can read and reproduce the work.
- Contents: code, demos, and a short guide to run the backend locally.

## Quick Start
1. Clone this fork:

```bash
git clone https://github.com/PrakashDivya123/power_rangers.git
cd power_rangers
```

2. See `requirements.txt` and `voxel_ai_toolkit/README.md` for setup instructions.

## Notes
- Large binaries and DB files are intentionally excluded from this documentation branch.
- If you need large assets, contact the repo owner or check release assets.
